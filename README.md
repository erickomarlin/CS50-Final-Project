About the app: Fat Tracker is health web app. The main feature is calculating calorie that users get from the food they have eaten. The uniqueness of this app is the activities that this app suggests are not sports! they are activities that most every people do everyday. Kids, teenagers, youths, adults, seniors, male, female, anybody could do. They don't have to go to the gym, running, playing ball, etc. The app would suggest the activities that they could do at home during their spare time! Interesting!
How to use the app: every user would visit the signup page at the very beginning. User has to signup first. Finish sign up, user would be asked some questions regarding their preferences. After answering all the questions, app directs user to the food and activity page. After filling the food that user has eaten and activity that user has done, the app would bring user to the recap and result page. In result page, there would be 3 clickable button (Total, Burn All Calorie, Lose Weight). Total: just show the excess of loss profit. Burn All Calorie: app suggests some activities to do. Lose Weight: app suggests some activities to do, nutrients needed, and the next day's food plan.
Selection of foods: rice, egg, chicken breast, egg.
Selection of activities:wash dish, wash car, wash clothes, study, read, make up room, clean the floor, play video games, plank, sing, walk.
Database: this app use MongoDB to store users' data.
Stacks: HTML, Tailwindcss, Javascript, MongoDB, ExpressJs.
